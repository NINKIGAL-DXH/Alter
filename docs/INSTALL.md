Alter 0.1.0 — personal preview

Open the DMG, then copy Alter.app to Applications. The application requires macOS 14 or newer. Liquid Glass is used on macOS 26 or newer; older supported macOS versions use standard material.

This build is ad-hoc signed. It is not Apple Developer ID signed or notarized, so Gatekeeper may block it. Verify the repository and SHA-256 checksum. If you trust the build, follow the macOS-provided Privacy & Security workflow yourself; do not disable Gatekeeper or remove quarantine as an installation shortcut. A distributable notarized build requires your Developer ID certificate and Apple notarization credentials, which are not bundled or requested by this prototype.

The first launch does not scan or delete anything. Downloads access is requested only when you start a scan. Full Disk Access and administrator passwords are not required; unreadable paths are skipped and reported.

Cleanup is limited to old installer files inside Downloads. Selection starts empty. Review the confirmation list before moving anything. Files go to Trash, never permanent deletion; the History page can restore them if the Trash item still exists and the original name is free. Moving items to Trash does not immediately release disk space.

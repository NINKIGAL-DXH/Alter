# Anchor 模式

Anchor 是应用内的沉浸屏保，不是 macOS 屏幕保护程序插件，也不接管锁屏、密码或系统休眠。

在侧栏底部选择 **Anchor · 静静停留**，粘贴文字并保存，选择现有图片轮播或固定图片，再进入。文字空缺时只显示 Anchor 名称，不使用角色语录代替用户原文。空行分段；长段按完整字符分页（每页最多 72 个字符），最多 8,000 字；文字仅存在本机偏好设置中，不写进公开源码。画面每 22 秒切换，可手动前后翻页。控制按钮闲置 4 秒后隐藏，移入鼠标重新显示；Esc 或 ⌘⇧A 退出，菜单栏也保留退出入口。

## 冻结的含义

- 模式是所有 Alter 窗口共享的状态；整个原有工具界面卸载，菜单栏停止状态采样。
- 任务入口检查模式状态，不能开始扫描、清理、维护、更新或启动项操作；旧的确认计划和选择清空。
- 当前任务尚未结束时不进入，不会把文件写操作暂停在中途。辅助目录查询取消并等待返回后，才进入活动状态。
- 应用目录读取也归入单任务管理，避免遗留的脱离管理的后台任务。
- 已交给终端的管理员任务不会被屏保强行终止。应用记录其授权期限、执行预算和退出宽限；该时段结束后才能进入。
- 退出后回到原页面，状态自动刷新保持关闭，不自动重启之前的任务。
- 冻结仅针对 Alter，其他应用和 macOS 自身继续运行。已有索引数据保留供退出后使用。

## 视觉与资源

文字生成 Core Text 字形轮廓；macOS 26 将 Clear Liquid Glass 作用在字形上，叠加轻微明暗折射感与高光边缘。旧系统回退轻薄材质；减少透明度、增强对比度或不能生成轮廓的彩色字形使用可读的纯色文字，避免漏字。减少动态效果关闭漂浮和转场动画。

字形仅在文字或窗口尺寸变化时重新排版。浮动最多 24 fps，窗口不活跃时暂停；每次只加载当前图片，复用已有 20 MiB 缩略图缓存，解码尺寸最多 1600 像素。不联网、不加入启动项、不阻止睡眠，也不要求新系统权限。

参考：[Apple Liquid Glass 自定义视图](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views) 与 [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)。这是 Alter 的装饰文字设计，不表示 Apple 为屏保文字规定了这种样式。
